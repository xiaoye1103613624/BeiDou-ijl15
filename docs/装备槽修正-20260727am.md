# 魂戒穿戴闪退 /「数据无效」修正（2026-07-27am）

戳记：`FIX_RING_CRASH_20260727am`  
客户端：`BeiDou-Client_1\ijl15.dll` ≡ `BeiDou-ijl15\out\Release`  
服务端：需 rebuild `InventoryManipulator`（`isCash` 戒槽路由）

## 魂戒是什么

- 物品：`1115201`–`1115234`（一阶…满阶.魂魄戒指），`islot=Ri`，**`cash=1`**
- 有 `Effect/CharacterEff.img/11152xx` 特效引用（点装戒）
- **不是**服务端 SoulOrb 武器宝珠系统

穿魂戒时若看到「数据无效」，优先怀疑：**点装戒槽不同步** 被用户记成该 tip，或偶发订婚包；根因修复仍按下方 cash 槽。

## 闪退根因

1. 魂戒 `cash=1` → 合法装备位是 **−152/−153**（及 −112…），不是 −52/−53  
2. 服务端旧逻辑用 `dst <= -100` 判断 cash → 客户端常送 **−52** 时当普通戒落库  
3. 客户端 GetItem/SetItem 的 **cash 地址路径**（slot&lt;−100）**未挂** −53 影子 cave；DrawHasItem 却读 **−52 空隙 / g_ring53ZRef**  
4. 结果：栏上**无图标** → 再穿走替换/二次 SetItem → **闪退**

## 修复

### 服务端 `InventoryManipulator.equip`

- `cashRing = ii.isCash(itemId)`（不是 `dst<=-100`）
- cash 且 `dst` 在 −1…−99 → `dst -= 100`
- preferEmpty：cash 用 `−152/−153/−112…`，普通用 `−52/−53/−12…`

### 客户端 `shoulders.cpp`

- Bound 位点 early cave：`−152→−52`、`−153→−53`，再 `cmp −55`（避开未挂钩的 cash ZRef 路径）
- Addr cave 仍别名 −152/−153；影子 −53/−54/−55 不变
- 戳记 `FIX_RING_CRASH_20260727am`

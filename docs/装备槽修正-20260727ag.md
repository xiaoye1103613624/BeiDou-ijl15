## 2. 根因（PE 已证）

CUIEquip 绘制 @`7FEE90`（BP≠51）：

```
mov edi, [ecx-0x1A0]   ; ecx=[ebp-20h]=Char+0x293+(BP-1)*8
                       ; BP52 → [Char+0x28B] = −52 ZRef item*
mov esi, [ecx]         ; TSecType 脏值
...
test esi,esi / ForceNormal → 7FEEDB
```

Continue `@7FEEE2`：`mov esi,edi` → **blit 用的是 edi（角色库存）**。

原生 `7FEEDB`（`8B 4D EC 33 C0 39 01`）**只**用 `[ebp-14h]` 判 ZF，**不改 edi**。

`[ebp-14h]` 在循环里是 **UI 对象 +0xC 的 ZRef walker**（`lea eax,[edi+0xC]`），每槽 +8；**未为 BP52 扩展**，常为空。

af 的 `do52`：

```
mov edi, [[ebp-14h]]   ; ← 错：用 UI walker 覆盖已正确的 Char item*
```

→ GetItem(−52)/tip/swap 正常；绘制 esi=0 → **空槽**。BP53 走 `g_ring53ZRef` 不受此伤。

# FIX_RING34_RELOG_SYNC_20260727aq

## 现象
重登后红标 3/4 戒指消失（反复出现）。护肩 −20 正常。

## 根因（已用 SQL 证明）
- **库里一直有**：`xiaoye1` char1 仍有 `−52`/`−53`（与护肩 −20 同一 `inventoryitems` 落库路径）。
- **不是没持久化**，是 **登录解码** 原生 `cmp esi, 0x33`（51）会跳过 BP52/53；客户端 UI 空，服务端仍穿着。
- 护肩 ≤51，登录解码本来就能进，所以看起来「护肩好、扩展戒坏」。

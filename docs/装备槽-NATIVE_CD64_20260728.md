# FIX_HT_CASH_OVERFLOW_20260728

## 原因
装备 HitTest 表 `BE2260` 只有 **50** 格（BP1–50），后面紧挨现金装坐标表 `BE23F0`。  
往 index 51+ 写红 3/4 坐标 = **盖掉现金帽子等坐标** → 帽子跑位、双 tip、拖不进 3/4、装卸异常。

## 修复
- DLL 内独立 HitTest 表（56 槽），`GetBodyPartFromPoint` 改指这张表
- 恢复现金表默认坐标
- pendant2 不再往 PE HitTest[≥50] 写

## 部署
已编进 Client_1 `ijl15.dll`（戳记 `FIX_HT_CASH_OVERFLOW_20260728`）。  
仍用 **cd64 EXE**。

# 进图闪退 /「数据无效」修正（2026-07-27an）

戳记：`FIX_ENTER_INVALID_20260727an`  
客户端：`BeiDou-Client_1\ijl15.dll` ≡ `BeiDou-ijl15\out\Release`  
服务端：需重启（`InventoryManipulator` + `PlayerLoggedinHandler` 迁移）

## 现象

选角后**进入地图瞬间闪退**，提示「数据无效」（或相近无效文案）。

## 根因（双轨证据）

### 1) 结婚包 tip（文案错配，非进图主因）

| 证据 | 说明 |
|------|------|
| IDA `CWvsContext::OnMarriageResult` case 11 | `AddTail` + `GW_MarriageRecord::Decode` + `StringPool(0x109D=4253)` 弹窗 |
| `WeddingPackets.OnMarriageResult(id,…)` | `writeByte(11)` — Cosmic 订婚成功语义 |
| `PlayerLoggedinHandler` | **不**发 `OnMarriageResult`；仅 `OnNotifyWeddingPartnerTransfer` |
| 中文池原 #4253 | 「此请帖无效．」（用户常记成「数据无效」） |

结论：case 11 tip 是订婚成功错配，**不是**选角进图发包；已改 tip 文案 + 服务端 dropMessage。

### 2) am 点装戒 remap → 进图闪退（主因）

| 证据 | 说明 |
|------|------|
| am `GetItem/SetItem_CashRingRemap_cave` | 登录现金装备同步 `SetItem(−152/−153)` → 改写到 −52/−53 |
| 服务端 am `preferEmpty` | 魂戒 `cash=1` 落库 **−152/−153** |
| `addItemInfo` | cash 段写 bodypart 52/53 → 客户端走 −152/−153 |
| 进图时机 | `getCharInfo` 装备栏同步即触发 SetItem |

结论：am 为穿戴显示做的 −152↔−52 remap，在**登录 apply** 路径不安全 → 进图崩。

## 修复

### 客户端 `shoulders.cpp`

- `kRemapCashExtendedRings = false` — **不再**安装 bound-site CashRingRemap
- −52/−53 影子 / 普通六戒逻辑保留
- 戳记 `FIX_ENTER_INVALID_20260727an`
- `#4253` →「恭喜！你们已成功订婚。」

### 服务端

- 点装戒 `preferEmpty` 仅 **−112/−113/−115/−116**（禁止 −152/−153）
- 登录 `getCharInfo` 前 `migrateCashRingsOffExtendedSlots`：−152/−153（及误落 −52/−53 的 cash）迁到经典 cash 或背包

## 验证

1. DLL 串 `FIX_ENTER_INVALID_20260727an`，SHA ≡ Client_1；无 `FIX_RING_CRASH_20260727am`
2. **服务端已重启**（含本 Java）
3. 角色若测过魂戒：选角进图 **不闪退**、无无效 tip
4. 穿魂戒：落经典点装戒槽（红 1/2 等），红 3/4 仍可用于普通戒

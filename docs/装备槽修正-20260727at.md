## 现象
- 拖拽戒到红 3/4 → 重登仍在（as OK）

## 根因
`OnDoubleClicked` 空槽循环（`@4F0B62`）用 **`eax` = `anBodyPart` 游标**、**`ecx` = 下标**。占用后：`inc ecx; add eax,4; jl`。

`DblClick_OccBp53_cave`（ah 起）在 `call Ring*ZRefBase` / `mov eax, join` 后 **毁掉 eax**。BP52 已占用时继续循环 → `mov edx,[eax]` 读到代码字节当 bodypart → `[esi+edx*8+0x28B]` **AV**。

拖拽不走该空槽占用循环，故「只有双击炸」。  
`get_bodypart` 顺序 `{52,53,…}` 时，**只要红 3 有戒就无法扫到空的红 4**（ai「空 3/4 优先」在 52 占用时从未真正生效）。

全满时原生走 fail（不 replace）——修复后安全 **reject**，不闪退。

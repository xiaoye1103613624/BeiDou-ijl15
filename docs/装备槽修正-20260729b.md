# FIX_RING_DRAG_DST_UNEQUIP_20260729b

部署：`out\Release\ijl15.dll` → BeiDou-Client_1（SHA 一致）  
戳记：`FIX_RING_DRAG_DST_UNEQUIP_20260729b`  
服务端：`InventoryManipulator.equip` 去掉 preferEmpty / pickSixRingRotateSlot（需重启）

## 原因

1. **拖拽轮询**：`equip()` 在目标槽已占用时用 `preferEmpty` 改到其它空槽，六满时再 `pickSixRingRotateSlot` —— 拖拽发来的明确 `dst` 被覆盖。
2. **双击卸装**：`wear` 占用读 B 点写成 `0x4F2041`（落在指令中间），`ExpectBytes` 永不匹配 → B 路径仍读原生 Char gap，BP52–55 影子槽判定为空 → `wear` 返回 0。

## 修复

| 侧 | 改动 |
|----|------|
| Server | 戒指只保留点装槽 remap；**不再** preferEmpty / rotate；拖拽 `dst` 原样替换 |
| Client | `kWearOccB=0x4F203E` / join `0x4F2045`；A/Cash 不变 |
| Client | 背包双击六满轮询 `DblClick_RingFullRotate_cave@4F0B84` **保留**（仅 empty-search 失败路径） |
| Client | 装备栏双击多 BP 失败时不回退 empty-search |

4. 装备栏双击红 3/4 / 经典戒 → 卸回背包
